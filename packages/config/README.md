# @tower-guard/config

Shared build/lint/style configuration for the Tower Guard monorepo.

## Exports

| Path | Purpose |
|---|---|
| `@tower-guard/config/tailwind-preset` | Tailwind preset with shadcn theme tokens |
| `@tower-guard/config/tsconfig/base` | Library TypeScript base |
| `@tower-guard/config/tsconfig/vite` | Vite app TypeScript config |
| `@tower-guard/config/tsconfig/pwa` | Vite PWA app TypeScript config |
| `@tower-guard/config/tsconfig/library` | No-emit library TypeScript config |
| `@tower-guard/config/eslint` | Flat ESLint config |
